# 혈전 약리 시뮬레이터 (Antithrombotic Pharmacology)

혈액이 응고되어 혈전이 되는 과정을 직접 돌려 보고, 항혈소판제·항응고제·혈전용해제가
각각 어느 단계를 막는지 확인하는 교육용 웹 페이지입니다. 설치 없이 `index.html` 하나를
브라우저로 열면 됩니다.

## 무엇을 볼 수 있나

**세 가지 시나리오**

| 시나리오 | 내용 |
| --- | --- |
| 정상 지혈 | 혈관 벽이 찢어져 출혈 → 혈소판 마개 → 피브린 고정 → 복구 후 섬유소 용해 |
| 동맥 혈전 | 죽상반 파열, 고전단에서 혈소판이 쌓여 내강 폐색 → 하류 허혈 |
| 정맥 혈전 | 판막 주머니의 정체, 피브린이 적혈구를 가둔 적색 혈전 → 색전 |

**약 30종의 약물** — 켜고 끄면 같은 혈관에서 결과가 달라집니다. 혈소판 동원, 트롬빈 생성,
피브린 교차결합, 섬유소 용해를 각각 따로 억제하므로 계열별 실패 양상이 다르게 나타납니다.

- 아스피린·P2Y12 억제제를 켜면 혈소판 마개가 작아지고, 항응고제를 켜면 피브린이 성기어져
  마개가 떨어지며 재출혈합니다.
- 혈전이 생긴 뒤 혈전용해제를 투여하면 플라스민이 피브린을 끊어 혈관이 다시 열립니다.
  정상 지혈 시나리오에서 투여하면 지혈된 마개까지 녹습니다.
- 병용 조합에 따라 출혈 경향 막대와 주의 알림(금기, 상호작용, 해석 팁)이 바뀝니다.

**표적 지도 · 약물 가이드** — 1차 지혈 / 2차 지혈 / 섬유소 용해 3단 경로도에서 약물의
작용 지점을 보여 주고, 약물마다 표적·치료 목표·용법·부작용 발생 기전·금기·상호작용·
모니터링·역전 방법과 국내 대표 제품명을 정리했습니다.

## 구성

```
index.html                 배포본 (이 파일 하나로 동작)
build.py                   src/ 조각을 모아 index.html 생성
src/head.html              페이지 앞부분 (스타일, 시뮬레이터, 표적 지도, 약물 가이드 틀)
src/tail.html              페이지 뒷부분 (혈전용해제, 질환별 선택, 상호작용, 근거)
src/data.js                약물 데이터, 표적 지도 설명, 시나리오 단계
src/sim.js                 시뮬레이션 모형과 캔버스 렌더링
src/ui.js                  화면 연결 (약물 패널, 지도, 가이드, 알림)
figures/                   문서용 도해 2종 (섬유소 용해, 뇌졸중 시간창)
tools/make_figures.py      도해 PNG 생성 (Pillow + Noto Sans KR)
tools/doc_*.py             워드 문서(.docx)에 단원·제품명을 추가한 스크립트
```

`tools/` 의 문서 스크립트는 특정 경로의 .docx 를 전제로 하므로 그대로 실행되지 않습니다.
작업 방식을 남겨 둔 기록으로 보시면 됩니다.

## 시뮬레이션 모형에 대하여

기전을 보여 주기 위한 **정성 모형**입니다. 막대와 퍼센트는 상대값이며 실제 혈중 농도,
검사 수치, 출혈 확률이 아닙니다. 시간은 실제의 분·시간·일 단위를 수십 초로 압축했고,
와파린처럼 발현이 느린 약물은 치료 범위에 도달한 상태를 가정합니다.
